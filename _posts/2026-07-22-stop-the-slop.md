I've been using AI religiously for over 4 years now. I started with the very first iterations of [Github Copilot](https://github.com/features/copilot) when it was beta that was only capable of slightly smarter autocomplete. I continued using as it evolved in to an indispensable pair programmer and eventually moved on to more sophisticated tools when they became available. Cursor, Windsurf, Claude Code, Codex, OpenCode, pi, goose and so many other tools, LLM's and harnesses have been tools I've tried out, or drove daily for a period. These tools all have one thing in common, they'll solve the problem in whatever way they can even if that way is bad.

Since LLM's can generate text so quickly they tend to generate more, before the advent of "thinking" models developers really had to build out the concept, think through the design and the spec and then the LLM could implement it. I believe this forced function created better software and that we have become complacent accepting LLM output as is, with increasing less refinement.
